Gaps and what was not tested

  • Teacher screens: a made-up “Test Teacher” sample is being built so the teacher screens can be opened and reviewed; until then they show as blocked.
  • Operations role: opened screen by screen in the preview as a test Operations account (results in the checklist).
  • 200% zoom, screen readers, keyboard-only use: the dialog focus, keyboard and naming fixes were checked by script; a full manual pass is still needed.
  • Documents: payslip and document text formatting was checked as text; generated PDF and picture output was not compared by eye.
  • Slow and failed loads: covered for Payroll and Finance (saved copy → refreshing → updated / could not refresh) and for stale student forms; not for every screen.
  • Saves and sends: nothing in this preview writes anywhere. End-to-end workflow tests run in the separate writable test copy (see condition 4).
