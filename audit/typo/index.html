Type scale for approval

Patch 901 (with 900 reading its tokens and 880 for fonts/contrast) · preview with sample data, 25 Oct 13:50 · nothing deployed

What Misty is approving: one central type scale for the app screens. Finance Overview keeps its look (Fredoka One page titles, system sans for everything else with Chinese fallbacks, uppercase bold labels, bold tabular figures, purple ink, muted grey); every size moves up about one step so body text is 15–16px and nothing is under 12px. Text now follows the phone/browser text-size setting. Documents (payslips, receipts, agreements, invoices, reports) are not touched.

BEFORE = production app.html today. CURRENT = phase-1 proposal (app.html + patches 830–898, system sans). TYPE = CURRENT + 900 + 901. Screenshots are taken in a test browser with Fredoka One loaded locally; the Arvo/Rockwell fonts in BEFORE could not load in the test browser, so BEFORE shows a serif fallback — on real phones it uses Arvo.
