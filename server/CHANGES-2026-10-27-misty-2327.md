## 1412 · Team Chat: Retry for pictures and voice messages
- A picture (1–5) or voice message that did not send now shows "Not sent · Retry" like text. Retry sends the same pictures / recording,
  caption, reply and options again with the same client id, so the server never posts it twice (if the first try did arrive, the retry just
  returns that message). A draft typed in the box meanwhile is kept.
